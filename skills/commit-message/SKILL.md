# Commit message

1. Read recent history with `git log --oneline -20` to learn the style.
2. Write a subject of 72 characters or fewer, in the imperative mood.
3. Add a body only when the reason for the change isn't obvious.
4. Never add a `Co-authored-by` trailer unless the user asks for one.

See `examples.md` in this folder for good and bad examples.
